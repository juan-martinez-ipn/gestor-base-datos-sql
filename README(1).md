
# 🗄️ Gestión y Modelado de Bases de Datos
> Conjunto de scripts y ejemplos que demuestran dominio completo de SQL, diseño de estructuras relacionales y consultas para análisis de negocio.

## 📚 Contenido
✅ Creación de tablas, definición de claves primarias y foráneas (Modelado de datos).
✅ Consultas `SELECT`, `WHERE`, `ORDER BY`.
✅ **`INNER JOIN`, `LEFT JOIN`**: Unión de múltiples fuentes de información.
✅ Funciones de agregación: `SUM()`, `COUNT()`, `AVG()`, `MAX()`.
✅ Agrupación y filtrado avanzado: `GROUP BY`, `HAVING`.
✅ Inserción, actualización y limpieza de registros.

## 💼 Aplicación
Estas habilidades son fundamentales para la integración de datos y la generación de reportes confiables, tal como se requiere en entornos de procesamiento de información a gran escala.
